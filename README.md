# Xray Panel — Railway MVP

پنل فارسی و راست‌چین برای مدیریت اولیه کاربران و Inboundها.

## امکانات نسخه اول

- ورود مدیر با JWT
- داشبورد
- مدیریت Inbound
- ساخت و حذف کاربر
- UUID خودکار
- تعیین حجم کاربر
- تعیین تاریخ انقضا
- SQLite
- سازگار با Railway
- رابط فارسی و RTL

> این MVP برای مدیریت داده‌ها و ساختار پنل است و نصب یا اجرای خودکار Xray Core روی Railway را انجام نمی‌دهد.
